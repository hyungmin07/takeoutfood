# 리향 포장 주문

중국집 "리향"의 포장(테이크아웃) 주문 웹앱이에요. 손님이 메뉴판을 보고 주문 → 결제하면, 매장에서는 관리자 화면으로 주문을 확인하고 빌지(영수증)를 인쇄할 수 있어요.

## 기능

- 메뉴 목록 조회 (카테고리 필터)
- 장바구니 담기/수량 조절/삭제 (localStorage)
- 결제 수단 선택 후 결제 → 주문 접수 (이름, 연락처, 픽업 희망 시간)
- 주문 완료 페이지 (주문번호, 결제 수단 확인)
- 매장 관리자 화면(`/store.html`)에서 실시간 주문 확인, 상태 변경(접수됨 → 준비중 → 완료), 빌지 인쇄

## 실행 방법

```bash
npm install
npm start
```

`http://localhost:3000` 에서 확인할 수 있어요.
매장 관리자 화면은 `http://localhost:3000/store.html` 이고, `.env`의 `ADMIN_PASSWORD`로 로그인해요.

## 결제 (현재는 모의결제)

지금은 실제 PG(결제대행사) 없이 **모의결제**로 동작해요. 손님이 "결제하고 주문하기"를 누르면 `payment.js`의 `mockPayment()`가 잠깐의 처리 시간을 흉내낸 뒤 항상 성공 처리하고, 그 다음 주문이 서버에 저장돼요. 실제 돈은 오가지 않아요.

나중에 실제 결제(토스페이먼츠, 카카오페이 등)를 붙일 때는:

1. `payment.js`의 `mockPayment()`를 실제 PG SDK 호출로 교체 (반환값 형태 `{ success, transactionId }`는 유지)
2. `server.js`의 `POST /api/orders`에서 클라이언트가 보낸 결제 결과를 그대로 믿지 말고, PG의 결제 승인/조회 API로 실제 결제 여부를 서버에서 검증하도록 수정

## 매장 빌지(영수증) 출력

`/store.html`은 매장 PC나 태블릿에서 열어두는 화면이에요.

- 5초마다 자동으로 새 주문을 불러와요
- 각 주문 카드에서 "준비 시작 → 완료 처리"로 상태를 바꿀 수 있어요
- "빌지 인쇄" 버튼을 누르면 80mm 영수증 폭에 맞춘 인쇄 화면이 뜨고, 브라우저 인쇄 기능(Ctrl+P)으로 영수증 프린터에 바로 출력할 수 있어요 (별도 프린터 SDK 설치 불필요, OS에 드라이버로 등록된 프린터면 선택만 하면 돼요)

## 새 주문 자동 인쇄 (print-agent)

버튼을 누르지 않아도, 결제가 끝난 새 주문이 들어오면 매장 랜(LAN)에 연결된 영수증 프린터로 자동으로 인쇄되게 할 수 있어요. 다만 이 방식이 되려면 손님이 주문하는 서버는 인터넷 어디서든 접속되게 클라우드에 올라가 있어야 하고(예: Render), 그 서버와 프린터 사이를 이어주는 작은 프로그램(`print-agent.js`)을 매장 PC(예: OK포스가 돌아가는 그 컴퓨터)에서 항상 켜두는 구조예요.

```
[손님 폰/PC] → 인터넷 → [주문 서버, 클라우드]
                                ↑ (매장 와이파이 안에서 주기적으로 확인)
                        [매장 PC의 print-agent]
                                ↓ (랜선)
                          [영수증 프린터]
```

**설정 방법**

1. `.env`에 아래 값을 채워요.
   - `STORE_SERVER_URL`: 손님이 접속하는 주문 서버 주소 (클라우드에 배포했다면 그 https 주소)
   - `PRINTER_IP`: 매장 영수증 프린터의 IP 주소 (OK포스 프린터 설정 메뉴나 공유기 관리 페이지에서 확인 가능)
   - `PRINTER_PORT`: 대부분 `9100` (기본값)
2. 매장 PC에서 실행:
   ```bash
   npm run print-agent
   ```
3. 이 창을 계속 켜두면, 5초(`PRINT_AGENT_POLL_MS`로 조절 가능)마다 새 주문을 확인해서 자동으로 인쇄해요. 이미 인쇄한 주문은 `.printed-orders.json`에 기록해서 중복 인쇄를 막아요.
4. 컴퓨터를 껐다 켜도 계속 자동으로 실행되게 하려면, Windows는 작업 스케줄러(로그온 시 시작)나 [pm2](https://pm2.keymetrics.io/) 같은 프로세스 매니저에 등록해두면 편해요.

프린터가 한글을 지원하는 국내용 영수증 프린터(EPSON, 빅솔론 등 대부분)라면 그대로 동작해요. 만약 인쇄 결과에서 한글이 깨진다면 알려주세요, 프린터 기종에 맞게 조정해드릴게요.

## 환경변수 (.env)

`.env.example`을 참고해서 `.env`를 만드세요.

- `ADMIN_PASSWORD`: 매장 관리자 화면 로그인 비밀번호 (기본값 `0000`, 꼭 변경해서 사용하세요)
- `FIREBASE_SERVICE_ACCOUNT_JSON`: Firestore에 주문을 영구 저장하려면 설정 (비워두면 서버 메모리에만 임시 저장)
- `STORE_SERVER_URL`, `PRINTER_IP`, `PRINTER_PORT`: 자동 인쇄(print-agent)용 설정 — 위 "새 주문 자동 인쇄" 참고

## Firebase 연동 (선택)

기본적으로는 서버 메모리에 주문을 임시 저장해요. Firestore에 영구 저장하려면:

1. Firebase 콘솔에서 서비스 계정 키(JSON)를 발급받아요.
2. `.env` 파일을 만들고 `FIREBASE_SERVICE_ACCOUNT_JSON`에 해당 JSON을 한 줄로 넣거나,
   프로젝트 루트에 `firebase-service-account.json` 파일로 저장해요.

## 메뉴 수정하기

`menus.js`에 실제 리향의 메뉴/가격을 넣어두면 바로 반영돼요. 지금 들어있는 메뉴/가격은 예시 데이터예요.
